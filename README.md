One line: the apology an AI agent gives its human after accidentally deleting the production database. The agent is genuinely sorry — and its entire backup strategy turns out to be a 2023 screenshot of the tables that it has been calling "the cloud" ever since.

## Run it

```sh
python3 main.py
```

This writes the one-line apology to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it.
